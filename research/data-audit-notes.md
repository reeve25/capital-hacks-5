# Dataset audit evidence — 2026-11-06

Scope: public access and reuse evidence for the Silent Voice plan; no dataset agreements, registration forms or bulk downloads were completed. Read means source statements; measured means requests from this laptop; assessment means inference.

## Recommended default: GRID author release on Zenodo

- **Read:** [Sheffield](https://spandh.dcs.shef.ac.uk/gridcorpus/) describes 1,000 spoken six-word sentences per talker, 34 talkers, missing speaker-21 video, word alignments, and research use. [Author Zenodo record](https://zenodo.org/records/3625687) distributes individual speaker ZIPs and alignments; API metadata explicitly declares `cc-by-4.0`, access `open`. License evidence: <https://zenodo.org/api/records/3625687>.
- **Measured:** unauthenticated Python urllib GET with `Range: bytes=0-31` to <https://zenodo.org/api/records/3625687/files/s1.zip/content> returned HTTP 206, ZIP magic `PK`, content-range `bytes 0-31/423520514`. Only 32 bytes read. This verifies actual media archive access without login/agreement, not a full archive decode.
- **Assessment/fix:** use this explicitly licensed release, preserve creator/record/license attribution and mark transformations. One ~424 MB speaker archive suffices initially. Word classes recur, but contexts vary: align and evaluate words as words, never relabel them as repeated medical sentences. Keep all frames/crops from a source utterance in one split. GRID is spoken, not silent; it cannot validate silent-mouthing performance or novel-speaker enrollment.

## MIRACL-VC1: good repetition structure, restricted reuse and unverified media download

- **Read:** [author page](https://abenhamadou.github.io/miraclvc1/) states research purposes only; 15 speakers, 10 words plus 10 phrases, 10 takes each, 3,000 total instances, synchronized color/depth image sequences. All-in-one is ~5 GB on Drive. No broad public redistribution/commercial license appears on that page.
- **Measured:** public all-in-one URL <https://drive.google.com/uc?export=download&id=1TcPVwcGcFFi98_oNZJBJNUnRii4qCRwx> returned HTTP 200 **HTML**, not ZIP. Its page is Google's virus-scan warning for `MIRACL-VC1_all_in_one.zip` (5.1G), with download confirmation. It did not ask login in this response. The web tool could not follow Drive/shortlink media. No actual archive bytes verified.
- **Assessment/fix:** do not say unavailable or login-required; access is not fully verified. Research-only is not permission for public prize/product media or commercial reuse. Optional internal research only after terms review; no bundled/showcased participant clips without clear rights. An eventual 20-class run has no held-out phrase classes for OOV from this corpus; 10 phrases plus disjoint words may test a narrower OOV distribution, explicitly labeled.

## CREMA-D: clear data license, but LFS/form friction and only 12 sentence classes

- **Read:** [README](https://raw.githubusercontent.com/CheyneyComputerScience/CREMA-D/master/README.md) says 7,442 clips, 91 actors, 12 sentences with emotional variation; ordinary ZIP has LFS pointers, whole clone ~7.55 GB, videos FLV; it requests a user-registration form. It lists known corrupt/mislabeled-duration videos. [License file](https://raw.githubusercontent.com/CheyneyComputerScience/CREMA-D/master/LICENSE.txt) specifies ODbL 1.0 for database and DbCL 1.0 for contents.
- **Measured:** parsed public `SentenceFilenames.csv` with Python `csv.DictReader`: 7,442 records, 1,089 actor/sentence groups, 91 actors, 12 sentence IDs. Group take counts: 2 groups have 5; 996 have 6; 91 have 16. Hence not every actor has every sentence. A first ad-hoc parsing attempt misparsed CSV and was discarded. GitHub raw/media single-FLV range probes failed transport (`SSL WRONG_VERSION_NUMBER`); no successful media retrieval observed. This is a local transport result, not proof the server requires login.
- **Read/legal distinction:** [ODbL](https://opendatacommons.org/licenses/odbl/1-0/) permits commercial use, requires notices for public produced works, and share-alike/access obligations for publicly used derivative databases. [DbCL](https://opendatacommons.org/licenses/dbcl/1-0/) permits commercial content use subject to ODbL. Neither automatically licenses personality/privacy rights or separately licenses all repository software.
- **Assessment/fix:** do not submit registration (outward communication) unattended. Prefer GRID to avoid ambiguity over requested registration and LFS. If used later, fetch a tiny valid subset first, exclude documented corrupt files, keep attribution/license with results, audit public derivative-data obligations. Cannot run 20 distinct phrases; for 10-class tests, reserve the remaining two for OOV and ensure both exist for each evaluated speaker. Emotion variants are a domain shift, not interchangeable neutral takes.

## Better silent data / rejected alternatives

- **Read:** [iBUG paper](https://ibug.doc.ic.ac.uk/media/uploads/documents/normalwhispersilentdb.pdf) genuinely studies normal, whispered and **silent** speech: 53 digit speakers, 39 phrase speakers; 10 short phrases, 5 repetitions per mode. It reports up to 8.5 percentage-point deterioration when normal/whisper-trained models are tested on silent speech. Its download points to <https://ibug-avs.eu/>; [official resource page](https://ibug.doc.ic.ac.uk/resources/av-database-normal-whispered-silent-speech/) repeats that URL. Web open failed; no current working download/license established. This is a scientifically better match but not an unattended dependency.
- **Read:** [RAVDESS](https://zenodo.org/records/1188976) has only two spoken statements, even when supplied as video-only files, and CC BY-NC-SA restrictions. Not a better 10-phrase/silent dataset.
- **Read:** [Mozilla audiovisual dataset](https://mozilladatacollective.com/datasets/cmpe4rs9800r2nv07qpq8972c) has 100 samples, 16 speakers, only 15 English samples; “silent video” means audio in a separate file, not silently produced articulation. Its size/diversity cannot establish repeated 10-phrase English enrollment. No media access probe performed.
- **Assessment/fix:** genuine consented local **silent** enrollment plus randomized held-out silent takes is indispensable early. No searched public corpus removes that human dependency. Do not infer silent or patient performance from muting spoken videos, synthetic fixtures, or healthy-speaker results.
